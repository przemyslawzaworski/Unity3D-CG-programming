# Shader and feature catalog

An index of the shader examples in [Unity3D-CG-programming](https://github.com/przemyslawzaworski/Unity3D-CG-programming), based on the supplied local snapshot reviewed on 26 October 2026.

**Coverage:** 343 standalone shader source files (306 `.shader`, 36 `.compute`, 1 `.raytrace`), plus shader programs embedded in 2 C++ files, organized into **319 examples/features**. Associated C# scripts and selected required data files are listed with their feature.

## How to use this catalog

- Each row describes one independent example or one complete feature. Matching filenames are grouped; differently named files are also grouped when their code forms one pipeline. Collection folders retain separate rows for independent examples.
- Links open the corresponding files on GitHub. Paths retain the exact spelling and capitalization of the local snapshot; the links target the `master` branch and may change as the repository evolves.
- Most root examples target Unity's Built-in Render Pipeline. `URP` and `NeuralShaders/NeuralSDF.shader` target URP; `GLSL` examples use OpenGL/OpenGL ES; `DXR` uses DirectX 12 ray tracing. Other requirements and known limitations are mentioned where visible in the source.
- Descriptions come from static source inspection. This catalog does not certify compilation or behavior in a particular Unity version.

## License convention

The License column follows the repository owner's requested classification: **MIT** for examples without a ShaderToy reference in their code; **Creative Commons Attribution-NonCommercial-ShareAlike 3.0 Unported License.** for examples containing a `shadertoy.com` reference. The scan includes the shader code and its associated C#/C++ source. For a combined feature, a ShaderToy reference in any source file gives the whole row the CC classification; source links are included in that cell for traceability.

The existing [README](https://github.com/przemyslawzaworski/Unity3D-CG-programming/blob/master/README.md) declares CC BY-NC-SA 3.0 for the entire repository. The owner explained that this was a blanket declaration for the previously unorganized collection; this catalog records the requested finer-grained classification. A ShaderToy link is used here as a classification rule, not as independent verification of the linked author's license. Preserve original author credits and notices in the source, including third-party code referenced outside ShaderToy.
